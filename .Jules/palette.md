## 2025-05-15 - [DaisyUI Form Integration in Highly Custom Voice EFB Settings and Checklist Components]
**Learning:** Standard Tailwind utility form inputs (like simple input and select elements with manual borders and background rules) can result in visual inconsistencies across light and dark theme boundaries in a multi-themed system. Transitioning them to DaisyUI form selectors (`select`, `checkbox`, `range`) guarantees immediate theme integration while improving touch target compliance. Moreover, ensuring accessibility by explicitly linking labels via `htmlFor` attributes on all sliders, selects, and text inputs guarantees a screen-reader friendly and highly cohesive UX.
**Action:** Always prefer DaisyUI native semantic elements for form components, sliders, and checkboxes rather than writing arbitrary custom border/background utility overrides, and verify `htmlFor` pairing on every single interactive input.
